=== ISRO DATA SOURCES (REAL APIs/PORTALS) ===

1. MOSDAC (mosdac.gov.in)
   - Meteorological & Oceanographic Satellite Data Archival Centre
   - Run by Space Applications Centre, ISRO
   - Has "API based Access" under Data Access menu
   - Requires free registration
   - Missions available:
     * INSAT-3DR, INSAT-3D, INSAT-3DS (meteorological)
     * KALPANA-1 (meteorological)
     * INSAT-3A (multifunctional)
     * MeghaTropiques (tropical weather)
     * SARAL-AltiKa (ocean altimetry)
     * OCEANSAT-2, OCEANSAT-3 (ocean colour, scatterometry)
     * SCATSAT-1 (scatterometry/wind)
   - Open data products:
     * Atmosphere: Bayesian MT-SAPHIR rainfall, GPS water vapour,
       GSMap ISRO Rain, METEOSAT8 cloud properties
     * Land: 3D volumetric DWR, inland water height, river discharge,
       soil moisture, SPADEX-1 earth viewing data
     * Ocean: global surface current, sea surface salinity, Indian
       mainland coastal products, ocean subsurface, oceanic eddies,
       sea ice occurrence probability, wave renewable energy

2. Bhuvan API (bhuvan-app1.nrsc.gov.in/api)
   - ISRO's Indian Geo-Platform
   - Requires access token (free registration)
   - APIs available:
     * Proximity: postal/hospital details, village geocoding,
       village reverse geocoding
     * Thematic Statistics: LULC 50K stats, LULC 50K AOI-wise stats,
       LULC 250K stats, LULC 250K AOI-wise stats
     * Routing: shortest path API
     * Geoid: ellipsoid-to-geoid conversion

3. ISRO Data Portal (isro.gov.in/DataPortal.html)
   - Central data hub (may be intermittently available)

4. VEDAS (vedas.nrsc.gov.in)
   - Value Added Earth Observation Data and Services
   - Vegetation indices, crop monitoring, forest fire, flood mapping

5. Bhuvan Panchayat
   - Rural-level geospatial data

=== WHAT MAKES RUMI ACTUALLY USEFUL FOR ISRO SCIENTISTS ===

1. CROSS-MISSION CORRELATION
   RUMI's knowledge graph links INSAT rainfall data with OCEANSAT ocean
   data to find monsoon-ocean coupling patterns that a scientist looking
   at one dataset would miss.

2. AUTOMATED ANOMALY DETECTION
   RUMI already has anomaly_detector.py. Feed it MOSDAC time-series and
   it flags unusual patterns: cyclone formation, drought signals, algal
   blooms, unusual sea surface temperatures.

3. LITERATURE + DATA FUSION
   RUMI reads arXiv papers AND pulls real satellite data, then checks if
   published theories match actual observations from Indian instruments.
   "Paper claims X, but OCEANSAT-3 data shows Y."

4. HYPOTHESIS GENERATION FROM INDIAN DATA
   "Given INSAT-3DR cloud top temp dropping 15K over Bay of Bengal in
   48h, combined with OCEANSAT-3 SST > 29C, what is the probability of
   cyclogenesis?" RUMI can generate and rank these hypotheses.

5. GROUND TRUTH VALIDATION
   Bhuvan's LULC data can validate satellite-derived land cover
   classifications. RUMI's reproducibility_engine.py handles this.

6. MONSOON PREDICTION MODELS
   Combine INSAT atmospheric profiles + OCEANSAT ocean data + historical
   patterns from arXiv to generate monsoon onset/withdrawal predictions.

7. DISASTER EARLY WARNING
   Automated pipeline: satellite data -> anomaly detection -> hypothesis
   generation -> alert. Cyclones, floods, droughts, forest fires via
   VEDAS integration.

=== HONEST ASSESSMENT ===

- ISRO APIs are less mature than NASA's clean REST + DEMO_KEY pattern
- MOSDAC requires registration; Bhuvan needs access token
- Documentation is less standardized — expect some trial/error with
  actual API response formats
- The RUMI integration code itself is straightforward (3 files following
  existing patterns)
- The hard part is testing against live ISRO endpoints and handling their
  auth flow
- MOSDAC open data (rainfall, soil moisture, ocean) is freely available
  and the most immediately useful
- Bhuvan geocoding/stats are useful for Indian-context research
